## Phase 2 scientific orbit data

`/data/orbits/phobos.bin`, `deimos.bin`, `titan.bin`, `triton.bin`, `charon.bin`, and `ceres.bin` contain NASA/JPL Horizons scientific data, acquired 2026-09-24. Source: https://ssd.jpl.nasa.gov/horizons/ . Per-file `.provenance.json` records the complete queries, API versions, reference frame, units and binary transformation. These are numerical orbital elements, not imagery; the application computes approximate blended positions locally. `/data/corrections/callisto.bin` is derived from NASA/JPL Horizons minus astronomy-engine 2.1.19, with its own query provenance. Credit NASA/JPL for the ephemerides and astronomy-engine (MIT) for the analytic base. No NASA/JPL endorsement is implied.
