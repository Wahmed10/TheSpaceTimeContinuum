# 0009 - Osculating snapshots replace rounded mean-element positions

The Phase 2 plan proposed JPL's mean-element table as a position source for five moons. JPL explicitly limits that table to describing general orbit shape/orientation, not ephemeris computation: https://ssd.jpl.nasa.gov/sats/elem/ . Direct implementation produced large Titan/Triton epoch discrepancies and accumulated drift. The original experimental model, reference vectors and failed-check diagnostics remain recorded; its parameters were not adjusted to fit test outputs.

Decision: use locally propagated, smoothly blended **osculating** Kepler elements from NASA/JPL Horizons for Phobos, Deimos, Titan, Triton, Charon and Ceres. This is a deliberate change to P2.2's source/model choice within the existing PositionProvider and frame-tree contracts. The raw mean-element model is not used by the renderer.

Each offline table stores regular epochs in TDB, with ICRF-equatorial elements relative to the parent (Sun for Ceres). At runtime, propagate the two adjacent osculating solutions to the requested time; blend positions using smoothstep. Velocity includes both the weighted Kepler velocities and the derivative of the blending weight. This avoids phase-unwrapping aliasing for fast moons and is continuous in both position and velocity at table knots. No extrapolation is allowed. Provider output is km/km/s and always labelled `approximate`, method `kepler-2body`.

Spacing: Phobos 1 day; Deimos/Titan/Triton 4 days; Charon/Ceres 16 days. Six binary tables total 7,709,552 bytes (about 7.35 MiB), excluding provenance JSON. They are loaded once from the application origin, not fetched from JPL by browsers. Offline acquisition is sequential and cached, and stops on errors.

Validation uses 50 independently acquired off-grid vectors per body across 1900-2100, including both timeline ends. These vectors were not used to build the tables. The predeclared tolerances and measured maxima are in `docs/science/osculating-validation.json`. Maximum observed errors: Phobos 24.62 km, Deimos 18.05 km, Titan 32.76 km, Triton 12.65 km, Charon 0.076 km, Ceres 159.18 km. These are sampled measurements, **not continuous error bounds**. Existing planet, Moon, Galilean, Kepler and trajectory test thresholds are unchanged.

Consequences: all 21 catalog bodies have supported position providers. Their cards distinguish corrected analytic, analytic, and approximate orbital models. Six bodies remain generic lit spheres pending Phase 3 artwork. This adds CPU table storage/network bytes, not GPU texture storage. MeanElementsProvider remains an experimental/general mathematical implementation; two known expected-failure checks document why the rounded-table path was rejected. Astronomy-engine's internal allocations remain a separate P2.2 limitation.
