# 0003 — One deterministic TDB clock

Context: Independent feature timers would let planets, camera targets, and UI disagree.

Decision: Store TDB seconds since J2000. A single SimulationClock drives each frame. Include IERS leap seconds and the millisecond TDB–TT approximation. Explicit leap-second ISO strings are supported. Before 1972, dates approximate UT1 using the library's delta-T model. Future leap seconds are unknown.

Consequences: Pass TT directly to `AstroTime.FromTerrestrialTime`; the plan's UTC round-trip would substitute the library's future delta-T model and add drift. The UTC inverse tests allow 2 microseconds due to float64 rounding over 1900–2100 (the original 1 microsecond aspiration is not claimed). LIVE reads the device wall clock. UI notifications are capped at 4 Hz.
