# Phobos and Deimos display models

September 28, 2026. Models and matching surface atlases come from NASA/JPL-Caltech's [Phobos](https://science.nasa.gov/resource/phobos-mars-moon-3d-model/) and [Deimos](https://science.nasa.gov/resource/deimos-mars-moon-3d-model/) downloads under [NASA media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/). Original GLBs remain in ignored `assets/source/`; acquisition URLs, hashes, output counts and transformations are recorded in `docs/licensing/mars-moon-assets.json`.

`pnpm.cmd exec tsx tools/assets/build-mars-moons.ts` extracts the mesh and material's base-color image together. It uses the already installed Three.js meshoptimizer-based simplifier, weighting normal and UV differences and targeting 20% of the original triangle count. It retains the source origin and axes. Source coordinate magnitudes are consistent with kilometers; positions are divided by catalog mean radii (Phobos 11.267 km, Deimos 6.2 km) so the existing scientific/display-radius split still applies. Scientific landmark registration and rotation are pending P3.4; no shape orientation accuracy claim is made here.

The SHP1 binary stores vertex/index counts, signed 16-bit positions at 1/16384 mean radius, signed 8-bit normals, and unsigned 16-bit UVs/indices; gzip reduces transport size. The runtime validates counts, length and indices, normalizes normals, and calculates a bounding sphere. Position quantization alone is below half a metre per coordinate; mesh simplification error is separate and requires visual review. The normal/UV attributes follow the simplified topology. No displacement is derived from image brightness.

Both atlases are 1024-square ETC1S maps with mipmaps, served at all quality tiers. Phobos is reduced from a 2048-square source; Deimos retains its 1024-square source size. The atlas uses glTF's image/UV convention, without the Y inversion applied to cylindrical globe textures. Original image shading, blur and uneven coverage remain. A nonmetallic rough material replaces the source model's artistic 0.5 metalness.

The four new files total 423,579 bytes. All public assets, including both compressed shapes, total 79,961,515 / 80,000,000 bytes. The asset gate counts shapes as well as textures; no assets are moved outside the budget. Only 38,485 bytes remain. Conversion stages closed files outside the public tree and checks the whole package before publication.

Irregular meshes are retained across LOD and quality changes. Camera focus/zoom clearance uses the model bounding extent; physics still uses catalog radii and positions. Existing sphere-based picking remains approximate and needs moon interaction review during P3.4. Disposal follows the existing scene geometry lifecycle. Unit checks cover non-spherical bounds, atlas ranges, counts and corrupt/truncated payload rejection. Browser checks capture day/quarter views at LOW/HIGH and assert geometry identity survives quality changes; picking and precision suites also run for this increment. Hardware rendering remains a separate evidence requirement.
